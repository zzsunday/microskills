## 1. Annotate the reference with Bakta

Use the exact FASTA passed to VariantDetective `-r`. Preserve sequence identifiers using `--keep-contig-headers`. Do not annotate query assemblies to interpret reference-coordinate SNPs. Record reference identity (checksum when practical), software/database versions, paths, and commands. Reuse an existing annotation only after checking reference identity and contig IDs.

Resolve a validated Bakta environment and database from project configuration; do not guess a database path or add genus/species defaults. Inside a compute allocation:

```bash
set -euo pipefail
: "${REF:?Set REF to the reference FASTA used for detection}"
: "${BAKTA_DB:?Set BAKTA_DB to the verified Bakta database directory}"
: "${SLURM_CPUS_PER_TASK:?Run inside a Slurm allocation}"
bakta_out="results/reference_bakta"
test -s "$REF"
test -d "$BAKTA_DB"
test ! -e "$bakta_out" && test ! -L "$bakta_out"
mkdir -p results

bakta "$REF" \
    --db "$BAKTA_DB" \
    --keep-contig-headers \
    --threads "$SLURM_CPUS_PER_TASK" \
    --skip-ncrna-region \
    --skip-crispr \
    --output "$bakta_out" \
    --prefix reference

test -s "$bakta_out/reference.tsv"
```

Use a distinct directory per reference. Inspect existing outputs before execution; do not use `--force` to replace results silently. Validate major Bakta outputs and reference sequence IDs, not only process exit. Canonical outputs include `reference.tsv`, `.gff3`, `.gbff`, and `.fna` under that directory.

## 3. Map SNPs to reference genes

For each sample with SNPs, inside Slurm and after compatibility checks:

```bash
set -euo pipefail
: "${SAMPLE:?Set SAMPLE to the query sample ID}"
: "${SNP_TABLE:?Set SNP_TABLE to the verified final variant TSV}"
: "${Anno:?Set Anno to the matching reference Bakta TSV}"
: "${SNP2GENE_PYTHON:?Set SNP2GENE_PYTHON to Python with click and pandas}"
snp2gene_script="$HOME/03_scripts/snp2gene.py"
annotation_out="${SAMPLE}_snp2gene.tab"
test -s "$snp2gene_script"
test -s "$SNP_TABLE"
test -s "$Anno"
test ! -e "$annotation_out" && test ! -L "$annotation_out"

"$SNP2GENE_PYTHON" "$snp2gene_script" \
    --snp "$SNP_TABLE" \
    --anno "$Anno" \
    --out "$annotation_out"

test -s "$annotation_out"
```

## 4. Validate and interpret results

Verify output row count equals input table row count, original variant identities are preserved, annotation fields exist, and no contig mismatches occurred. Record detection and annotation status separately. Expected outputs are the original calls, reference Bakta results, and `<sample>_snp2gene.tab`.

The mapper uses inclusive reference coordinates for `cds` and `sorf` features. Genic results contain `Region`, `Feature_Type`, `Gene` (falling back to locus tag), `Locus_Tag`, feature bounds, strand, and product. Overlapping hits are joined with `|`. Intergenic results contain nearest left/right coding features on the same contig and coordinate distances. These neighbors are linear and do not wrap around circular contigs. Other feature types are not included in this coding-feature classification.

The annotation columns are:

```text
Region Feature_Type Gene Locus_Tag Feature_Start Feature_Stop Strand Product
Intergenic_between Left_Gene Left_Locus_Tag Left_End Distance_to_Left_bp
Right_Gene Right_Locus_Tag Right_Start Distance_to_Right_bp
```

This is positional gene-context annotation. Do not infer synonymous/nonsynonymous effects, amino-acid changes, phenotype, or causality. Preserve independently produced functional-effect annotations without fabricating missing ones.
